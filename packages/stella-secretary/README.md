# @stella/secretary

将官方 DSH 桌面客户端扩展为可切换的 Stella 私人秘书。当前组合支持官方 DSH `0.2.2-alpha.3` 与 `0.2.2-rc.1`；macOS Apple Silicon 的发布安装包为本轮桌面验证目标。其他版本和平台须单独验收。

## 用户安装

1. 安装受支持的官方 DSH 客户端，打开原生“插件 / Plugins”页面。
2. 通过原生插件管理器安装 Stella 的 `.tgz` 安装包。完成后退出并重新打开 DSH；插件的安装、启用、停用及卸载按重启生效使用。
3. 使用窗口顶部的切换按钮选择 **Stella** 或 **DeepSeek Harness**。模式切换即时生效，不需要重启，也不会另开浏览器或网页服务。分别保存窗口的模式和上次位置。

安装使用 DSH 的宿主、模型、会话、工作区、插件管理和桌面承载，不修改官方 App 文件。包内的五组界面扩展由原生 Bundle 在当前 Profile 中装配，保留官方模块身份以兼容现有插件；它们是明确标注来源和 MIT 许可的 Stella 维护衍生模块，不是官方发行包。卸载后重新打开 DSH，恢复原生界面；会话、配置和业务记录保留。

## 使用与数据

Stella 提供 事务、日程、简报、账单与定时的应用入口。事务和日程可展开当前页面内的原生会话；账号和设置复用原生窗口，自动化复用 DSH 调度器。秘书会话显式使用 `stella` Preset，切回 DSH 沿用用户原来的默认 Agent、模型与会话。模式切换本身不调用模型。

官方 Desktop 使用自带的 Python 运行环境执行随包领域服务，无需用户另装 Python。Web 开发预览仍需要 Python 3.9+。业务 SQLite 位于当前 Profile 的 `stella/business/`，与原生 Host 工具和页面共用；旧独立客户端的数据通过显式离线迁移导入，不在安装时自动读取。功能差异以源码仓库 `product/feature-parity.md` 为准，不把安装闭环当作所有原六项功能已经全部迁完。

Apple 日历与提醒事项由可选原生插件 `@stella/apple-sync` 管理：点击同步纳入全部来源并保留分类／清单；授权由用户操作发起。Stella 设置只管理助手名称；学校与邮箱账号由各自插件管理。工具使用宿主当前会话的可用性、访问模式、审批和凭据设施，不再保存额外的 Stella 逐工具白名单。停用时暂停所属自动化；重新启用不自动恢复已暂停的定时任务。

业务采用已选择的本机可信应用模式，同账号的其他插件和执行工具可能访问本机数据，不承诺系统级隔离。宿主工具限制、凭据撤销复核，以及私人来源的主对话／委托执行检查继续有效。自动化发送用户填写或保存的任务；生成简报会将所选来源内容交给用户配置的模型。打开页面或切换模式不会自动发送私人业务数据。

## 开发与兼容

完整来源与界面扩展摘要见 `vendor/NATIVE-UI-PROVENANCE.json`，许可随衍生模块保留。开发安装、构建、官方 Desktop 验证和已知限制见源码仓库 `product/README.md`、`product/compatibility.md`。官方客户端的 UI 根节点不支持本组合的无重启热替换；不将热安装／热卸载作为已支持能力。

事务默认直接展示全部事务，未完成和已完成分组平铺；重复事务在列表中直接完成本次。Stella 本地重复事务按其时区投影一个当前待办，编辑和删除仍针对原系列。Apple 导入的重复事务保留来源实际到期日，完成后由 Apple 返回的结果推进；已完成的独立来源记录保留，不按同名自动合并。

日程与事务支持右键或 Shift+F10 打开操作菜单，选择“显示简介”查看标题备注、日期时间、重复提醒和分类／清单等信息，并进入原有编辑或删除确认。日期视图中的点击同样可查看简介，事务列表的详情和子事务入口保留。只读、已完成历史及待 Apple 确认记录按既有能力限制操作；拷贝仅写入用户可见文本。菜单不提供产品没有的邮件发送、剪切粘贴或创建复制项目。

0.1.55：事务页详情与编辑统一为右侧面板，保留左侧列表及筛选状态。子事务树、重复记录、完成/重开、清单、标签和提醒沿用现有功能；支持草稿保护、固定操作区及窄窗口。

0.1.54：日历内日程和事务的详情、编辑与新建统一使用右侧面板。面板独立滚动、底部固定操作；未保存修改提供继续编辑或放弃，保存失败保留草稿。窄窗口显示全宽详情，沿用现有只读、重复和同步规则。

0.1.53：日程页重排日期导航、视图切换与时间网格；日程和事务统一浅灰账户分组侧栏，日历保留多选显示与底部月历，事务保留单清单导航。数据、来源权限与同步规则沿用现有实现。

0.1.52：事务页增加清单侧栏和快速添加，任务行显示备注预览；清单管理统一搜索、颜色、Apple 账户、草稿、分项权限与待确认操作。子事务缺省继承父事务清单，已有数据不迁移。

AgentHub 已拆为独立开发者插件 `@stella/agent-hub`，仅在 DSH 工作台提供入口；Stella 不再拥有协作运行时、数据写入、界面或协作 Skill。旧协作数据只读迁移到独立插件，原始数据保留。
