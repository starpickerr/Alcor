# AgentHub

DSH 工作台中的独立开发者工具，用于开发任务分工、执行记录与交流。通过 DSH 原生插件管理器独立安装、启停和卸载；不依赖 Alcor，不在 Alcor 页面或工具列表添加入口。

当前支持原生 DSH 开发助手。各步骤使用独立执行会话，继承发起会话的模型；外部 Codex/Claude Code 持续会话接入尚未实现。

## 安装与入口

安装本包并启用后，在 DSH 原生侧栏选择 AgentHub。单独使用时需要 DSH 基础与 Web/Desktop 组合。协作设置可创建开发助手会话；选择模型后返回工作台创建任务。只浏览页面不会调用模型。

## 数据与迁移

当前 Profile 的 `agent-hub/agent-hub.sqlite3` 是唯一协作数据 owner。第一次启动会只读导入已迁入 `alcor/business/agent-hub.sqlite3` 的旧协作数据；旧 KV 委托由更新后的 Alcor 交接，Alcor 未运行时读取旧数据域导入。导入按记录保留标识、消息、参与者、步骤、执行历史与幂等记录；原数据保留，冲突失败不覆盖，重复启动不重复导入。此前未确认结束的执行显示结果未知，需核对后显式重试。

与旧 Stella 协作运行时不兼容；同一 Profile 已启用旧 Stella 时，应同时更新到已拆分的版本。停用/卸载撤销界面和后台任务，数据与原生会话保留。

## 开发与验证

在仓库根运行 `npm run product:hub:pack`。当前仅在固定官方 DSH 版本验证，不能通过放宽版本声明替代兼容检查。群聊扩展保留原始消息和任务结果；独立的厂商 Agent 接入能力另行评估。
