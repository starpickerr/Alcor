## 行为和数据来源

- 按实际存在的工具、页面、Skill、MCP贡献分组，标题显示数量；服务契约放进折叠技术信息，无重复连接状态或启停按钮。
- 工具行优先使用提供者标题、实际说明，点击/键盘展开真实名称、来源、完整描述及已发布的输入/输出schema。没有参数定义时明确提示，不把缺失解释为无参数。
- MCP工具数据来自已发现且公开给Agent的实例；只传递标题和schema等展示字段，不改变原annotations/read_only或执行检查。停用、未启动或失败时不把缓存工具显示为已发现。
- 插件数据来自同一用户inventory中的manifest及已发布contributes，适配工具依据明确的source.plugin_ids归属；ID按类型区分，页面和工具同名不会互相覆盖。仅声明的工具保留可查看定义，不伪造运行可用性。已有注册但不在静态展示目录的插件适配器可从已加载类获取公开说明和参数，不重新实例化或注册工具。
- 页面名称和入口复用侧栏的显式导航绑定。没有宿主导航项的已声明页面使用共享PluginPageHost路由，先核对当前插件/页面登记和状态，仍走原后端审核及iframe/Bridge；业务实现不复制到能力页。
- 保留顶部信息卡和四标签，概览不再重复完整工具说明；配置表单/CAS和运行页沿用原实现。布局使用Stella的Inter/系统中文字体、surface/content/accent token，紧凑行与细分隔线；极窄内容区缩小图标、保留名称换行，完整JSON只在展开后渲染并局部滚动。
