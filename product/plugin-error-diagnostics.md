## 错误契约

MCP 查询失败继续以 isError 回执返回 JSON 文本 `{error_code,message}`；eLearning 已有两字段契约不变，邮件补齐同样的安全诊断。消息来自固定目录，不包含原始服务器异常、认证 URL 或凭据。邮件 test_connection 保留原先 structuredContent.value 状态字段，并补充安全的 message。业务服务继续既有 OperationResult，错误码通过工作进程保留到消息；未知写入保持 status/sideEffects=unknown。

插件回执不等于宿主审批回执。网络、代理 DNS、学校服务、邮箱服务和本地文件错误均不能自动推断为审批拒绝。下载没有增加审批步骤，也没有关闭安全检查。Skill 按实际错误提示处理，替换文件前先下载验证，再备份旧文件；失败保留旧文件。
